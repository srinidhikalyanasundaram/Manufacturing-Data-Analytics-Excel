# Manufacturing Data Analytics

## Project Overview

This project focuses on analyzing manufacturing data using Microsoft Excel to understand production performance, machine operations, maintenance risks, anomalies, and key performance indicators (KPIs).

The project includes data cleaning, data validation, lookup tables, KPI calculations, Pivot Tables, analysis, and dashboard creation.

## Project Objectives

* Clean and validate the manufacturing dataset
* Analyze manufacturing and production performance
* Calculate important operational KPIs
* Identify maintenance-related risks
* Detect abnormal or anomalous records
* Analyze machine and production performance
* Create Pivot Tables for business analysis
* Build a management dashboard
* Generate meaningful business insights

## Dataset

The project uses a manufacturing dataset containing **1,000 records**.

The dataset includes manufacturing and operational information used for performance analysis and KPI calculation.

## Data Cleaning

The following data quality checks and cleaning activities were performed:

* Checked for missing values
* Checked for duplicate records
* Validated dates
* Checked data types
* Standardized inconsistent values
* Validated numerical fields
* Created lookup tables for assumptions and thresholds
* Added calculated fields required for analysis

The analysis covers:

* Operational performance

## KPI Analysis

Important manufacturing KPIs were calculated and analyzed to understand operational performance.

The workbook includes calculations and rules for:

* Production-related KPIs
* Quality metrics

## Pivot Table Analysis

Pivot Tables were created to summarize and analyze the manufacturing data from different perspectives.

These summaries help identify patterns, trends, and performance differences across manufacturing operations.

## Dashboard

The dashboard helps users quickly understand:

* Anomalies
* Production trends
* Operational performance
